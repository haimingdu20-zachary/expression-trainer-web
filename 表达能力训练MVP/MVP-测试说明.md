# 表达能力训练 MVP 测试说明

## 1. 安装

进入项目目录：

```bash
cd "/Users/mac/Documents/Codex/项目合集/表达能力训练MVP"
npm install
```

项目原始压缩包不包含 Sherpa-ONNX 模型，需要按照 README 下载模型并放入：

```text
models/sherpa-onnx-streaming-paraformer-bilingual-zh-en/
```

目录中至少应有：

```text
encoder.int8.onnx
decoder.int8.onnx
tokens.txt
```

启动：

```bash
npm start
```

## 2. 第一次测试建议

训练设置：

- 场景：工作汇报 / 述职
- 主题：我为什么建议推进这个方案
- 结构：工作汇报
- 时长：60 秒

表达时刻意测试：

1. 先说一段铺垫，看是否提示“先说结论”
2. 说出结论但不解释，看是否提示“补一个原因”
3. 说原因但不举例，看是否提示“来个例子”
4. 说完主体后继续展开，看是否提示“开始收尾”
5. 结束后生成报告
6. 点击“AI追问”
7. 再次录音，查看“前后对比”

也可以分别测试以下入口：

- 面试回答：讲一个项目经历，观察是否推动你说出行动和结果
- 讲清一个想法：讲一个观点，观察是否要求原因和例子
- 会议发言：先回应一个问题，再提出方案和行动
- 说服沟通：讲一个提案，观察是否追问对方收益和证据
- 即兴表达：随机选一个题目，限制在 60 秒内回答

## 3. 报告测试

需要在设置中配置 OpenAI、DeepSeek、Ollama 或其他 OpenAI 兼容接口。没有 AI 配置时，以下能力仍然可以测试：

- 录音
- 实时字幕
- 原有词库统计
- 表达结构导航
- 语速和停顿统计
- 重录对比

没有 AI 配置时，最终报告和 AI 追问会显示失败提示，这是预期行为。

## 4. 当前 MVP 的已知限制

- 逻辑阶段判断是启发式规则，不是严格的语义证明
- 语速使用识别文本量估算，不等同于专业语音学测量
- 停顿识别依赖麦克风音量阈值，不同环境需要调节阈值
- 重录对比暂时是整段指标对比，还没有句子级 diff
- AI 追问目前一次生成一个问题，不包含连续对话状态
