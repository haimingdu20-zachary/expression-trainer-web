# 表达练习室｜网页版 MVP

这是表达能力训练产品的网页端 MVP，适合通过 HTTPS 在桌面浏览器或手机浏览器中体验：

线上地址：<https://svf9v5n51r2vvjbq6qkeu.apigateway-cn-beijing.volceapi.com/>

- 选择训练场景、表达结构、目标时长和练习主题；
- 使用浏览器麦克风进行语音识别，显示实时字幕；
- 实时统计笼统词、填充词、犹豫词、表达密度、语速和停顿；
- 结束后生成结构复盘、节奏分析、逐句分析和前后对比；
- 训练记录和录音默认保存在当前浏览器，不上传原始表达；
- AI 出题区域当前使用本地题库，避免把模型密钥暴露到前端。

## 本地运行

直接用 HTTPS 静态服务器打开本目录即可。麦克风和浏览器语音识别通常需要 HTTPS 或 localhost，并建议使用最新版 Chrome / Edge。

## 部署

本目录已部署到 veFaaS，后续更新可在本目录运行：

```bash
vefaas inspect
vefaas deploy --yes
```

正式上线前仍需补充账号登录、跨设备数据存储和安全的 AI 后端代理；当前版本定位为可公开访问的网页 MVP 测试版。
